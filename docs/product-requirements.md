# プロダクト要求定義書 — 東証株価データベース

## ビジョン・目的
東証銘柄の日次株価(始値・高値・安値・終値・出来高)を毎日自動で取得・蓄積し、
25日/75日移動平均とあわせて一覧できるデータベース型のダッシュボードを提供する。
「今の株価が高値圏なのか安値圏なのか」を移動平均との比較で機械的に把握できることを目指す。

**本プロダクトは投資助言を行うものではなく、あくまで判断材料を提供するツールである。**

## ターゲットユーザーと課題
- 日本株(東証銘柄)を見ている個人投資家(自分自身)。
- 課題:
  - 毎日手動で株価を確認・記録するのは手間。
  - 終値だけを見ても、移動平均線との位置関係(高値圏/安値圏)が分かりにくい。
  - 過去データを自分で貯めておく仕組みがない。

## 主要な機能
1. 登録銘柄(`data/universe.csv`)の日次OHLCV(始値・高値・安値・終値・出来高)を毎日自動取得。
2. 取得したデータを SQLite データベース(`data/prices.db`)に蓄積(日々積み上がっていく)。
3. 一覧画面で、銘柄ごとの最新の始値・高値・安値・終値・出来高・25日移動平均・75日移動平均を表示。
4. 終値と移動平均の位置関係から「高値圏 / 中立 / 安値圏」を自動判定して一覧に表示。
5. コード・銘柄名で絞り込み、各列でのソート。
6. 銘柄をクリックすると、直近の値動きチャート(終値・MA25・MA75)と直近20営業日の詳細データテーブルを表示。

## 成功の定義
- 毎日ページを開くだけで、登録銘柄の最新の値動きと高値/安値圏の目安が確認できる。
- 過去データが日々蓄積され、後から振り返られる状態を維持できる。
- 運用コストゼロ(GitHubの無料枠のみ)で継続できる。

## ビジネス要件
- 個人利用が前提であり、収益化は対象外。
- 無料で利用できるデータソース(yfinance)を使用し、APIキー等の契約は不要とする。
- 静的ホスティング(GitHub Pages)で動作するWebシステムとする。

## ユーザーストーリー
- 利用者として、毎日自動で株価データが更新されてほしい。それにより、自分で取得作業をしなくて済むから。
- 利用者として、終値だけでなく25日/75日移動平均も並べて見たい。それにより、今が高値圏か安値圏か判断しやすいから。
- 利用者として、過去のデータが蓄積されてほしい。それにより、後から値動きを振り返られるから。
- 利用者として、銘柄コードや名前で絞り込みたい。それにより、見たい銘柄をすぐ見つけられるから。

## 受け入れ条件
- トップページを開くと、登録銘柄一覧が最新の日付のデータで表示される。
- 各行に始値・高値・安値・終値・出来高・MA25・MA75・判定バッジが表示される。
- 列見出しをクリックすると、その列でソートされる。
- 検索欄にコードまたは銘柄名を入力すると、一覧が絞り込まれる。
- 銘柄行をクリックすると、その銘柄の直近チャートと直近20営業日のテーブルが表示される。
- データ取得に失敗した銘柄がある場合、その銘柄だけ「取得失敗」と表示され、他の銘柄表示には影響しない。

## 機能要件
- FR-1: `data/universe.csv` に登録された銘柄コードについて、日次OHLCVを取得する。
- FR-2: 取得したOHLCVを `data/prices.db`(SQLite)に日付・銘柄コード単位で保存(既存日付は上書き、蓄積は継続)する。
- FR-3: 銘柄ごとに25日・75日の株価移動平均を算出し、`prices.db` に保存する。
- FR-4: 終値と移動平均の関係から「高値圏/中立/安値圏/判定不可」を算出する。
- FR-5: フロントエンドは `data/latest.json`(最新1件)と `data/history.json`(直近120営業日)を読み込んで表示する。
- FR-6: 一覧はコード・銘柄名・日付・OHLCV・MA25・MA75・判定の各列でソート可能。
- FR-7: コード・銘柄名によるフリーワード絞り込みができる。
- FR-8: 銘柄クリックで詳細(チャート・直近20営業日テーブル・判定理由)を表示する。

## 非機能要件
- データ取得に失敗しても、アプリ全体がクラッシュせず失敗銘柄のみエラー表示する。
- データ提供元(yfinance/Yahoo Finance)の障害・仕様変更の影響を受けやすいことを許容する。
- 個人利用の範囲であり、大量アクセスや同時多接続は想定しない。
- サーバー常時起動は不要。GitHub Pages + GitHub Actions の無料枠のみで運用できること。
