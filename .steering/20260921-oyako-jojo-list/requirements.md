# 要求内容 — 親子上場ウォッチリストの追加

## 背景
「次の親子上場の解消銘柄を予想しよう」という企画のために、東証に上場している
親会社と上場子会社の組み合わせ(いわゆる親子上場)を一覧にしたい。

本リポジトリは東証の全上場銘柄の銘柄マスタ(`data/prices.db` の `stocks` テーブル)と
日次株価を持っているため、「その銘柄が現在も上場しているか」を自前のデータで
判定できる。これが親子上場の一覧づくりで最も間違えやすい部分(2025〜2026年に
完全子会社化された銘柄を古い記事のまま載せてしまう)であるため、本リポジトリに
一覧ページを追加する。

## 変更・追加する機能
1. **親子上場ウォッチリスト**のページ(`oyako.html`)を追加する。
   - 親会社・上場子会社・親会社の持株比率・基準日・出所・備考を一覧表示する。
   - 区分(50%超 / 20〜50% / 比率未確認)での絞り込み、会社名・コードでの検索、
     持株比率・時価総額・コードでの並べ替えができる。
   - 判断基準と、確認できなかったことをページ内に明記する。
   - 資本関係が解消済みなどの理由で除外した組み合わせも、理由つきで載せる。
2. データファイルを追加する。
   - `data/oyako-jojo.json` — ページが読み込むもとデータ。
   - `data/oyako-jojo.csv` — 表計算ソフトで開く用。
3. 既存の一覧ページ(`index.html`)から新ページへのリンクを張る。

## ユーザーストーリー
- 利用者として、東証の親子上場の組み合わせを、親会社の持株比率とあわせて
  一覧で見たい。
- 利用者として、その数字がどこの情報に基づくのか(出所・基準日)を確認したい。
- 利用者として、どこまで調べられていて、どこが未確認なのかを知ったうえで使いたい。

## 受け入れ条件
- `oyako.html` が `data/oyako-jojo.json` を読み込み、171組の組み合わせを表示する。
- 区分の絞り込み・検索・並べ替えが動作する。
- 各行に持株比率の種類(議決権 / 所有株式数)、基準日、出所URLが表示される。
- 判断基準・未確認事項・除外した組み合わせがページ内に記載されている。
- `index.html` から `oyako.html` に移動でき、`oyako.html` から戻れる。
- 既存の株価一覧・銘柄詳細・チャート・日次の自動更新に影響を与えない。

## 制約事項
- データは調査時点(2026年9月20日)のスナップショットであり、自動更新はしない。
  株価データの日次更新(`scripts/fetch_prices.py`)とは独立している。
- 持株比率は各社IR・有価証券報告書などの公開情報に基づく二次データであり、
  網羅性は保証しない(東証の集計では上場子会社は2025年7月時点で215社)。
- 投資助言ではない旨をページに記載する。
