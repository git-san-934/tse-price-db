# yfinanceへの切り替え(J-Quants撤去) 要求

## 背景
J-Quants Freeプランの12週間遅延が解消されず、SBI証券からの手動ダウンロード自動化は
規約・セキュリティ上のリスクが大きいため見送った。無料かつ遅延の少ないデータ源として
yfinance(Yahoo Finance)への全面切り替えを決めた。

## 変更・追加する機能
- 株価取得をJ-Quants API(APIキー・レート制限あり)からyfinance(登録不要・無料)に切り替える。
- 銘柄マスタは、これまでJ-Quantsで取得した約4,449銘柄を静的な土台として使い続け、
  以後はJ-Quants APIへ再アクセスしない。
- レート制限がなくなるため、ローテーション方式(sync_state・RUN_BUDGET_MINUTES)を廃止し、
  毎回全銘柄を一括更新する方式に戻す。

## ユーザーストーリー
- 利用者として、追加費用や有料プラン契約なしに、翌営業日には最新の株価を見たい。
  それにより、J-Quants Freeプランの遅延問題を無料のまま解消できるから。

## 受け入れ条件
- GitHub ActionsのシークレットにJQUANTS_API_KEYが不要になる。
- 平日の自動実行で、全銘柄(約4,449)の株価が翌営業日には反映される。
- 既存の手動CSV取り込み機能(SBI証券等)は変わらず動作する。

## 制約事項
- yfinanceは非公式ラッパーであり、Yahoo Finance側の仕様変更で動かなくなるリスクがある
  (この開発環境からはYahoo Financeへのアクセスがブロックされておりローカル実写検証は
  できていない。GitHub Actions上での実行結果で確認する)。
- 新規上場銘柄は自動追加されない(静的な銘柄マスタのため)。
