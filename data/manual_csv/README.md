# 手動CSV取り込みフォルダ

SBI証券の個別銘柄「株価CSVダウンロード」でダウンロードしたファイルを、
このフォルダに**そのままの名前で**アップロードしてください
(GitHubのWeb画面で、このフォルダを開いて「Add file」→「Upload files」→
ドラッグ&ドロップ、で構いません)。

アップロード(push)されると、GitHub Actionsが自動的にファイルを読み取り、
`data/prices.db` の該当銘柄を更新します。J-Quants API(平日自動取得)より
新しい日付のデータが優先して反映されます。

対応しているファイル名: `TimeChart<証券コード><yyyymmdd>.csv`
(SBI証券のダウンロード時のデフォルト名。リネーム不要)

取り込み後もファイルはこのフォルダに残ります(再度pushされても同じ内容を
上書きするだけなので、削除しなくて構いません)。
